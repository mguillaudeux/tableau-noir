# Sources des données et crédits

Tableau Noir n'utilise que des données ouvertes. Les données brutes ne sont **jamais** copiées dans ce dépôt : le code les télécharge (ou les lit en local) au moment du calcul, et le site ne publie que des résultats calculés.

## Hudl StatsBomb Open Data

- Dépôt : <https://github.com/hudl/open-data> (anciennement `statsbomb/open-data`).
- Contenu utilisé : événements et images « 360 » (Coupe du monde 2022, Euro 2024, Bayer Leverkusen 2023/24, PSG en Ligue 1 2021/22 et 2022/23, CAN 2023…), finales de Ligue des champions 2009 → 2019 (événements).
- Conditions : *StatsBomb Public Data User Agreement* (usage non commercial, pas de redistribution des données). Toute analyse publiée cite StatsBomb comme source et affiche son logo : [`data/credits/statsbomb-logo.png`](data/credits/statsbomb-logo.png).
- Crédit affiché : « Données : Hudl StatsBomb Open Data ».

## Wyscout public dataset (Pappalardo et al.)

- Collection figshare « Soccer match event dataset » : <https://figshare.com/collections/Soccer_match_event_dataset/4415000>.
- Contenu : événements de ~1 900 matchs — saison 2017/18 des cinq grands championnats, Coupe du monde 2018, Euro 2016.
- Licence : CC BY 4.0 (métadonnées CC0).
- Citation : L. Pappalardo, P. Cintia, A. Rossi, E. Massucco, P. Ferragina, D. Pedreschi, F. Giannotti, « A public data set of spatio-temporal match events in soccer competitions », *Scientific Data* 6, 236 (2019). <https://doi.org/10.1038/s41597-019-0247-7>
- Crédit affiché : « Données : Wyscout, via Pappalardo et al. (2019), CC BY 4.0 ».
